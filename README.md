# 🎬 Yello

**Discover. Rate. Review. Repeat.**

Yello is a movie and TV show discovery mobile application inspired by modern film-tracking platforms. Powered by the TMDB API, Yello lets users explore trending movies and TV shows, discover new titles, manage their watchlists, and share their opinions through ratings and reviews.

## ✨ Features

- 🔐 **Authentication** — Sign up, log in, and reset your password.
- 🎥 **Movie & TV Discovery** — Browse trending and popular titles using live TMDB data.
- 🔍 **Search** — Find movies and TV shows by title.
- ❤️ **Favorites** — Save and manage your favorite titles.
- 🔖 **Watchlist** — Keep track of titles you want to watch later.
- ⭐ **Ratings & Reviews** — Rate movies and shows and share your thoughts.
- 👤 **User Profiles** — Manage your personal information and view your reviews.
- ⚙️ **Settings** — Update your profile and manage account preferences.

## 🛠️ Tech Stack

- **Frontend:** FlutterFlow / Flutter
- **Movie Data:** The Movie Database (TMDB) API
- **Backend:** Firebase
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **File Storage:** Firebase Storage, when configured

## 🎨 Design

Yello features a modern dark interface with a cinematic aesthetic, using a black background, vibrant yellow accents, and pink highlights.

## 🎯 Project Goal

Yello was developed as a university mobile application project to explore API integration, backend services, user authentication, database management, and mobile UI/UX design.

## 📌 Disclaimer

This product uses the TMDB API but is not endorsed or certified by TMDB. Movie and TV metadata and images are provided by TMDB.
